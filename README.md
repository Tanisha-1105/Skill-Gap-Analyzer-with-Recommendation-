🚀 Skill Gap Analyzer with AI Recommendations
Skill Gap Analyzer is an Android-based educational tool designed to help users identify and bridge knowledge gaps in technical and professional skills. The app leverages the Google Gemini AI API to provide dynamic, personalized learning paths based on real-time test performance.

🌟 Key Features
AI-Powered Assessment: Generates dynamic quizzes for any skill (Java, Figma, Python, etc.) using Generative AI.

Personalized Recommendations: Provides instant, actionable feedback and study resources tailored to the user's specific weak areas.

Professional PDF Reports: Generates a detailed, multi-page PDF report including:

A full Question & Answer Review with correct/incorrect markers.

A visual Competency Scorebox.

Formatted AI Recommendations with text-wrapping for readability.

Modern UI/UX: Built with Material Design components, featuring a smooth fragment-based navigation and a responsive "Back/Next" quiz flow.

Local Data Persistence: Uses a lightweight state management system (ViewModel) to ensure a seamless user experience during testing.

🛠️ Tech Stack
Language: Java / XML

Architecture: MVVM (ViewModel & LiveData)

AI Engine: Google Gemini 2.5 Flash API

Networking: OkHttp3 & Retrofit

Document Generation: Android PdfDocument API
